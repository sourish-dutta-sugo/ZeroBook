# Palette's Journal - Critical UX/Accessibility Learnings

## 2026-07-20 - Customizing KPI Card Transition Modes
**Learning:** Adding interactive UX customization controls for top-level layout states (such as KPI card presentation carousels) gives small retail users a highly personalized and pleasing interface experience. Standard flow structures using Jetpack DataStore allow these visual layouts to sync seamlessly and instantaneously across screens without requiring complex state management or database migrations.
**Action:** Always provide simple, toggleable, or chip-based controls in settings when introducing new visual presentation formats, using reactive preferences (e.g. DataStore) to coordinate instant UI updates.
