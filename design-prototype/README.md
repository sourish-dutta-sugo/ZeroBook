# ZeroBook Design Prototype

Standalone UI/UX design review artifacts. **Does not modify the Android app codebase.**

## Quick Start

1. **Browser review (fastest):** Open `index.html` in any browser
2. **Penpot review (editable):** Open your connected Penpot project — 4 pages are ready
3. **Full spec:** Read `ZEROBOOK_UI_DESIGN_SPEC.md` for all 120 screens + Figma mapping

## What's Inside

| File | Purpose |
|---|---|
| `index.html` | Interactive gallery — splash, dashboard, vouchers, parties, settings, reports, POS |
| `ZEROBOOK_UI_DESIGN_SPEC.md` | Complete screen inventory, design tokens, Figma kit mapping |

## Design Source

- **Reference:** [FinWise Finance Management UI Kit](https://www.figma.com/design/a3TG9T2MFvuS0RUJAA67tN/) (156+ screens)
- **App specs:** `FRONTEND_UI_SPECIFICATION.md`, `FRONTEND_DESIGN.md`, `APP_STRUCTURE.md`
- **Theme:** ZEROCOOL single palette (forest green `#1A5C45`, warm off-white `#F8F7F4`)
